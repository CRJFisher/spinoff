# Code Quality Fixes

Findings from a 10-agent review of the codebase after the 002.2 overview panel implementation and subsequent simplification (removing multi-backend abstraction, flattening to `spinoff/cmux.py`).

## 1. Critical fixes

### 1.1 Inline imports (violates `python-imports.md`)

- `spinoff/config.py:61` — `import sys` inside `load_config()` body. Move to module level.
- `tests/e2e/conftest.py:122` — `import os` inside `run_create_worktree()`. Move to module level.
- `tests/e2e/test_lifecycle.py:91` — `import os` inside test method. Move to module level.

### 1.2 Legacy shim (violates NO BACKWARDS COMPATIBILITY)

- `spinoff/state.py:161` — `pane_id` fallback in `load_state`. Remove `or wt_data.get("pane_id")`.

### 1.3 Dead code

- `spinoff/overview/template.py:155-160` — XHR fallback to `/action` in JS. No HTTP server exists. Remove the `try { var xhr... }` block entirely.
- `spinoff/cmux.py:62` — `project_name` parameter accepted by `create_workspace` but never used. Remove it and update all call sites.
- `spinoff/overview/__init__.py:57` — `OverviewInfo.pid` is always `0`, never populated with real PID. Either populate it or remove the field.
- `spinoff/coordination.py:113-154` — `propagate_error` and `propagate_recovery` have no production call site. Remove (YAGNI).

### 1.4 Stale naming

- `spinoff/create.py:215,227` — `tab_title`, `tab_cmd` should be `workspace_title`, `workspace_cmd`.

### 1.5 Assert in production

- `spinoff/overview/poller.py:182` — `assert entry.terminal_id is not None` is stripped by `python -O`. Replace with an explicit `if` guard or narrow the type at the call site.

### 1.6 Stale docstrings (violates documentation-style.md)

- `spinoff/sandbox.py:3-14` — Historical "replaces previous Docker/sandbox-exec approach" framing.
- `spinoff/config.py:6-7` — "replaces the old placeholder-replacement pattern" framing.

## 3. Error handling

### 3.1 Library function calls `sys.exit`

- `spinoff/config.py:60-67` — `load_config` calls `sys.exit(1)` for missing file. Should raise an exception and let CLI entry points catch it.

### 3.2 Unguarded JSON parsing

- `spinoff/config.py:69` — `json.loads` with no try/except. `JSONDecodeError` produces raw traceback.

### 3.3 Non-atomic config write

- `spinoff/config.py:134` — `save_config` writes directly. Should use temp+rename pattern like `save_state`.

### 3.4 Unguarded subprocess calls in `create.py`

- `create.py:148-151` — `git rev-parse --show-toplevel` with `check=True`, no try/except.
- `create.py:188-191` — `git rev-parse --abbrev-ref HEAD` same issue.
- `create.py:196-199` — `git worktree add` same issue.

### 3.5 Fire-and-forget cmux calls

- `spinoff/cmux.py:101,105` — `_run` return values discarded in `create_workspace` for rename and send. Failures invisible.

### 3.6 Overly broad exception handling

- `spinoff/overview/poller.py:102-103` — `except Exception` around pure `_compute_sleep`. Masks bugs.
- `spinoff/overview/poller.py:240-241` — `except Exception` in `_update_focused_workspace`. Redundant since `list_workspaces` handles its own failures.

### 3.7 Discarded return value

- `spinoff/overview/__init__.py:71` — `close_workspace` return value ignored; `close_overview` reports success even on failure.

## 4. Security

### 4.1 Path traversal

- `spinoff/overview/__init__.py:22` — `get_cache_dir(project_name)` does not sanitize `project_name`. A value like `../../../tmp/evil` escapes `~/.cache/spinoff/`.

### 4.2 Safety filter gaps

- `spinoff/overview/security.py` — All `_DANGEROUS_PATTERNS` are case-sensitive. `SUDO`, `--FORCE`, `RESET --HARD` bypass detection. Add `re.IGNORECASE`.
- `rm -r -f /` (split flags) and `rm --recursive --force /` bypass the `rm -rf` pattern.
- Network filter false-negative: if `localhost` appears anywhere in screen text, external `curl` commands are incorrectly allowed.

### 4.3 Secret redaction gaps

- `spinoff/overview/security.py` — `redact_secrets` misses uppercase env-var patterns: `GITHUB_TOKEN=`, `AWS_SECRET_ACCESS_KEY=`, etc.

## 9. Data flow

### 9.1 State file race condition

- Poller's read-modify-write cycle can clobber `create.py`'s concurrent `add_worktree`. No file locking exists.

### 9.2 Redundant config load

- `open_overview` re-reads config from disk when the caller (`create.py`) already has it. Accept config as a parameter.

### 9.3 `list_workspaces` selected field

- `cmux.py:145-168` — `selected` is stringified. `poller.py:236` compares against `"True"`, `"true"`, `"1"`. Normalize to `bool` at the cmux boundary.
