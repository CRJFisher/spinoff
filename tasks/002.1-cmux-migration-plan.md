## Terminal backend abstraction

### `spinoff/terminal.py` — Protocol

```python
class TerminalBackend(Protocol):
    def available(self) -> bool: ...
    def create_workspace(self, title: str, cwd: Path | None, command: list[str] | None, project_name: str | None) -> tuple[bool, str | None, str]: ...
    def close_workspace(self, terminal_id: str) -> tuple[bool, str]: ...
    def workspace_exists(self, terminal_id: str) -> bool: ...
    def set_title(self, terminal_id: str, title: str) -> tuple[bool, str]: ...
    def focus_workspace(self, terminal_id: str) -> tuple[bool, str]: ...
    def list_workspaces(self) -> list[dict[str, str]]: ...

    # cmux-only (WezTerm returns None / (False, "not supported"))
    def read_screen(self, terminal_id: str, scrollback: bool = False) -> str | None: ...
    def send_keys(self, terminal_id: str, keys: str) -> tuple[bool, str]: ...
    def notify(self, title: str, body: str) -> tuple[bool, str]: ...
    def set_sidebar_status(self, workspace_id: str, status: str) -> tuple[bool, str]: ...
    def set_sidebar_progress(self, workspace_id: str, progress: int) -> tuple[bool, str]: ...
```

cmux-only methods return harmless no-ops on the WezTerm backend. No `isinstance` checks needed in calling code.

### `spinoff/backends/__init__.py` — Auto-detection

```python
def get_backend(config: SpinoffConfig | None = None) -> TerminalBackend:
    """
    1. config.terminal_backend if explicitly set
    2. cmux if available (cmux ping succeeds)
    3. wezterm if available (wezterm cli list-clients succeeds)
    4. Raise RuntimeError
    """
```

### `spinoff/backends/cmux.py`

| Protocol method          | cmux command                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------- |
| `available()`            | `cmux ping`                                                                             |
| `create_workspace()`     | `cmux --window <id> new-workspace --cwd <path>` + `cmux rename-workspace` + `cmux send` |
| `close_workspace()`      | `cmux close-surface --surface <id>`                                                     |
| `workspace_exists()`     | `cmux --json list-workspaces`, check for id                                             |
| `set_title()`            | `cmux rename-workspace --workspace <id> <title>`                                        |
| `focus_workspace()`      | `cmux select-workspace --workspace <id>`                                                |
| `list_workspaces()`      | `cmux --json list-workspaces`                                                           |
| `read_screen()`          | `cmux read-screen --surface <id> [--scrollback]`                                        |
| `send_keys()`            | `cmux send-key --surface <id> <key>`                                                    |
| `notify()`               | `cmux notify --title <t> --body <b>`                                                    |
| `set_sidebar_status()`   | `cmux set-status --workspace <id> <text>`                                               |
| `set_sidebar_progress()` | `cmux set-progress --workspace <id> <value>`                                            |

Window targeting uses the `identify` pattern from [002.3](002.3-cmux-window-targeting.md).

## State model changes

Rename `pane_id` → `terminal_id` in `WorktreeEntry`. Add project-level fields to `.state.json`:

```json
{
  "window_id": "cmux-window-uuid",
  "overview_workspace_id": "cmux-workspace-uuid",
  "worktrees": [
    {
      "name": "fix-auth",
      "terminal_id": "cmux-workspace-uuid",
      ...
    }
  ]
}
```

`window_id` and `overview_workspace_id` are cmux-specific and ignored by the WezTerm backend.

## Config changes

Add to `spinoff.json`:

```json
{
  "terminal_backend": ""
}
```

Empty string = auto-detect. `"cmux"` or `"wezterm"` for explicit override.
